## QUÉ ES TECH DAY CALI 2026

El primer evento tecnológico de escala en Cali que reúne 8 comunidades tech para conectar talentos, compartir conocimientos e impulsar innovación en el Valle del Cauca.

- **Fecha:** 21 de Noviembre 2026  
- **Asistentes esperados:** 250+ profesionales tech  
- **Comunidades:** 8 comunidades tech unidas  
- **Propósito social:** Recaudar fondos para fundaciones de recuperación del Valle

## CATEGORÍAS DE PRESENTACIONES

### 1. KEYNOTE (30 minutos)  
- Charlas inspiracionales de apertura/cierre  
- Visión estratégica sobre tech  
- Speakers destacados/ejecutivos  
- Cupós: 3 máximo

**Temas ideales:**
- Transformación digital en empresas  
- Futuro del cloud en Latinoamérica  
- Liderazgo tech en tiempos de cambio  
- Ecosistemas tech locales

### 2. TALK (45 minutos)  
- Charlas técnicas profundas  
- Case studies y lecciones aprendidas  
- Tendencias y mejores prácticas  
- Cupós: 8-10

**Temas ideales:**
- AWS best practices  
- Kubernetes en producción  
- Microservicios y arquitectura  
- DevOps pipelines  
- Testing strategies  
- Cloud migrations  
- API design

### 3. WORKSHOP (90 minutos)  
- Sesiones prácticas y hands-on  
- Máximo 30-40 personas  
- Requiere laptops/equipos  
- Cupós: 4 máximo

**Temas ideales:**
- Deploy a Kubernetes en 60 minutos  
- AWS Lambda patterns  
- Docker y containerización  
- Infrastructure as Code  
- Python para DevOps  
- Frontend frameworks

### 4. LIGHTNING TALK (15 minutos)  
- Presentaciones cortas y puntuales  
- Quick tips y hacks  
- Inspiración rápida  
- Cupós: 5 máximo

**Temas ideales:**
- Tips de productividad  
- Herramientas útiles  
- Historias de carrera  
- Lecciones aprendidas (corto)
